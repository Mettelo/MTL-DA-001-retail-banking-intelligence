# Submission & Team Repository Guidance

This folder defines how participating teams must create, structure and submit their own GitHub repositories for **MTL-DA-001**.

## Contents

- `TEAM_REPOSITORY_STANDARD.md` — mandatory team repository structure
- `SUBMISSION_GUIDE.md` — end-to-end GitHub submission process
- `FINAL_SUBMISSION_TEMPLATE.md` — template each team copies into its own repository

Teams do **not** submit final work inside the Mettelo master repository.
