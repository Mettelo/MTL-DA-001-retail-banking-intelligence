# Project Governance

## Project Classification

Mettelo Project Studio — simulated engagement.

## Confidentiality

Project materials may only be used for authorised participation in the Mettelo project unless Mettelo explicitly approves broader publication.

Participants must not:

- publish the private repository;
- redistribute source-data packages contrary to their licence or terms;
- represent the simulated organisation as a real Mettelo client;
- disclose another participant's personal information;
- present team work as solely their own work.

## Portfolio and CV Use

Participants may describe their verified Mettelo Project Studio contribution accurately.

Any CV, portfolio or interview description should distinguish the Mettelo project engagement from paid employment with the simulated organisation.

## Source Data

Mettelo will retain an internal record of dataset provenance and reuse conditions.

Where data originates from a public or third-party source, required attribution and licence obligations remain applicable.

## Responsible Analytics

Participants should:

- avoid unsupported claims;
- document material assumptions;
- distinguish correlation from causation;
- consider bias and data limitations;
- avoid making automated decisions about identifiable individuals;
- escalate any potential privacy or licensing concern.

## Ownership and Contribution

Team-created artefacts should retain visible authorship/contribution history through GitHub wherever practical.

Mettelo may use completed project outputs for programme review, demonstration and participant evidence subject to the applicable project terms.
