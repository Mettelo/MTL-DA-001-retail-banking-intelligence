# Source Data

## Status

**Dataset selection / packaging in progress.**

The final source dataset for MTL-DA-001 will be an uncommon, realistic multi-table banking dataset or an approved Mettelo-packaged derivative with documented provenance and reuse conditions.

## Data Principles

The project dataset should:

- contain multiple related entities;
- retain realistic transaction-level behaviour;
- require non-trivial joins and modelling;
- contain enough imperfections to require data-quality investigation;
- avoid personally identifiable information;
- have clear reuse rights;
- be sufficiently uncommon that complete project solutions are not easily searchable online.

## Handling Rules

- Do not overwrite raw source files.
- Keep raw and transformed data separate.
- Document transformations.
- Do not upload data to external services unless approved.
- Large files may be stored outside GitHub and referenced here.

## Planned Data Areas

Likely entities include:

- customers / clients;
- accounts;
- transactions;
- loans;
- payments or standing orders;
- cards or account instruments;
- regional or contextual reference data.

The confirmed download/source link, provenance and data dictionary will be added after dataset verification.
